# 12：用现有能力接替归档命令面板

**What to build（交付行为）：** 从日常命令面板仍能找到原有自定义动作，并在等价行为明确后移除归档legendary。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** C；[治理SPEC](../spec.md) M01 / ID06；验收 AC08。

## 验收标准

- [ ] 盘点当前自定义命令、快捷入口及频率排序的实际使用方式，作为迁移验收清单。
- [ ] 用现有Telescope commands/keymaps和which-key接替命令发现，保留原入口或记录有明确替代的键位。
- [ ] 频率排序如不能等价保留，记录具体损失并保留原功能到取舍明确，不能静默删除。
- [ ] 原有自定义动作逐项演示；核实SQLite及其数据是否有其他消费者，保留用户数据。
- [ ] 确认为独占且迁移完成后才移除相应依赖，更新锁定、教程、设计和迁移回执。

## 范围与交付记录

不以删除插件或数据库作为第一步，不换搜索器。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
