# 09：统一状态栏模式并保持单次初始化

**What to build（交付行为）：** 多窗口下状态栏模式与插件配置一致，主题确定后只初始化一次。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** A；[治理SPEC](../spec.md) R06 / ID07；验收 AC07、AC10。

## 验收标准

- [ ] 明确选择全局或逐窗口状态栏，记录依据并消除globalstatus与laststatus冲突。
- [ ] 空启动、带文件启动、默认/_oem/_bug主题下最终选项和可见状态栏一致。
- [ ] 多窗口、tab切换和手动换主题可正常更新，无重复setup或状态丢失。
- [ ] 复用现有UI回归记录初始化次数与实际状态栏，保留显式首页命令。
- [ ] 同步状态栏设计、教程和R06台账。

## 范围与交付记录

不在本任务中实现自动项目主题或更换状态栏插件。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
