## 验收标准

- [ ] 核对官方兼容变更与当前锁，选定明确目标提交；已有版本合适则给证据并保留，不为更新而更新。
- [ ] 临时Git仓库验证blame、hunk导航、暂存/撤销、确认重置与Fugitive差异入口。
- [ ] 普通与大文件、多buffer和编辑器退出正常，不重现01的子进程遗留。
- [ ] 审查本批锁文件差异，保存恢复说明并验证相关行为。
- [ ] 同步插件审查、Git教程及维护回执，其他插件版本不混入本批。
