# 19：按活跃项目根自动切换主题

**What to build（交付行为）：** 项目切换时自动使用相应主题，帮助、文件树和终端保留最近活跃项目主题。

**Blocked by（阻塞依赖）：** [09 统一状态栏模式并保持单次初始化](09-statusline-contract.md)。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** E；[治理SPEC](../spec.md) R06 / ID07；验收 AC07。

## 验收标准

- [ ] 识别普通文件项目根、Git worktree及明确的非Git标记；空首页用cwd，不在每次BufEnter同步调用Git。
- [ ] 路径规则兼容Windows与macOS、重名仓库、monorepo和从外部目录打开绝对路径。
- [ ] 提供可移植的项目主题映射，具体仓库配色由配置表表达；未指定项目用现有默认主题。
- [ ] BufEnter与DirChanged只在目标主题变化时应用，特殊buffer不误切，失效主题给诊断。
- [ ] 多窗口/tab验证进程级主题和状态栏一致，不声称tab永久独立主题；记录切换成本并更新教程。

## 范围与交付记录

不新增项目/主题管理插件，不为每个tab实现独立整套配色。

依赖说明：09提供状态栏模式和单次初始化契约，主题切换以此做联合验收。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
