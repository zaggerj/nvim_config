# 18：收敛空首页与普通文本的启动工作

**What to build（交付行为）：** 空首页和普通文本不加载无关代码组件，使用命令或文件类型时功能及时就绪。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** E；[治理SPEC](../spec.md) R07 / ID07；验收 AC09、AC10。

## 验收标准

- [ ] 复测NormalFile触发条件，明确空buffer、特殊buftype、无文件名和普通代码的行为。
- [ ] Telescope及命令面板按真实命令/按键触发加载，首次使用可直接工作。
- [ ] 核实Neorg传递依赖的实际归属，norg和Neorg命令仍可用，不因同时用Obsidian而删除工作流。
- [ ] 覆盖空启动、指定代码文件、普通文本、大文件及从首页首次找文件。
- [ ] 同环境比较首屏与必要功能就绪，不能只延后服务赢得首屏；记录依赖加载与教程影响。

## 范围与交付记录

基于执行时实际保留的插件实施，不把命令面板迁移设成假阻塞；与其他配置任务串行合并。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
