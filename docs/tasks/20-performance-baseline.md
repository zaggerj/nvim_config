**What to build（交付行为）：** 以后每次优化都能在同环境对照首屏、功能就绪和搜索响应，给出可复现结果。

**Blocked by（阻塞依赖）：** [01 查清并修复Go回归超时与进程遗留](01-go-process-lifecycle.md)。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** 验证；[治理SPEC](../spec.md) R04、R07 / ID08；验收 AC10。

## 验收标准

- [ ] 记录机器、宿主/插件版本、项目、入口和样本，冷暖状态采用可解释且不删除用户缓存的测量办法。
- [ ] 分别采集首屏、高亮/状态栏、Coc RPC、具体语言服务就绪及搜索首次结果，不混用指标。
- [ ] 同数据集交替A/B并报告中位数及波动，不用历史1.39秒单次值直接计算收益。
- [ ] 明确shell/进程创建/绘制是否计入，测试正常退出；大仓数据集可重建且不提交无关源码。
- [ ] 保留当前基线、每批变更后按需复测，目标未量化处记录事实而不虚构SLA；关联性能记录。

本任务交付测量方法和当次基线，不顺手优化或替换插件。
