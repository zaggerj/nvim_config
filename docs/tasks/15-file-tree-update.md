# 15：定点维护文件树与文件定位

**What to build（交付行为）：** 文件树在明确兼容版本上保持定位当前文件、开关、分屏及文件操作，保留可恢复的锁版本。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** D；[治理SPEC](../spec.md) M02 / ID06；验收 AC08。

## 验收标准

- [ ] 核对锁定与上游API变化，按证据选择更新或保持版本。
- [ ] 真实临时目录覆盖展开/收起、查找当前文件、分屏打开与tab打开、隐藏项切换。
- [ ] 创建、重命名和删除仅在fixture中验证，确认取消不修改数据。
- [ ] 路径含空格及项目切换行为正确，特殊buffer不改变代码服务保护。
- [ ] 记录锁差异、恢复方式和文件树教程更新。

## 范围与交付记录

不修改用户项目文件，不引入另一个文件树。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
