# 03：让终端Esc只退出输入模式

**What to build（交付行为）：** 在终端按Esc回到普通模式，保留shell和前台程序；退出或停止任务使用明确入口。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** A；[治理SPEC](../spec.md) R02 / ID03；验收 AC04。

## 验收标准

- [ ] 消除后载入映射覆盖，最终终端Esc不发送exit及其他文本。
- [ ] 空闲shell和运行中的前台程序均可按Esc离开输入，再次进入后继续交互。
- [ ] fj和原生终端退出输入方式仍可用；现有明确停止任务入口行为可解释。
- [ ] 覆盖当前窗口和分屏终端，路径含空格时可启动；三个Windows入口行为一致。
- [ ] 通过实际终端job状态与接收文本验证，同步终端教程、键位表及问题记录。

## 范围与交付记录

不改变用户登录shell配置，不擅自终止已有终端。
