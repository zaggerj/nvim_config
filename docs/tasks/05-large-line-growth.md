# 05：补齐长单行编辑增长保护

**What to build（交付行为）：** 普通文件编辑或粘贴成超长单行时自动关闭该buffer昂贵分析，保留基本编辑且不影响其他buffer。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** A；[治理SPEC](../spec.md) R03 / ID04；验收 AC05、AC09。

## 验收标准

- [ ] 总量小于1MiB、单行30000字节的JS场景可触发保护，覆盖TextChanged和TextChangedI。
- [ ] 保持大于1MiB、20000行及20000字节单行三类阈值语义，验证阈值两侧。
- [ ] 输入、粘贴、撤销、读取及普通/大文件切换时，Coc、Copilot、Treesitter与折叠保护一致。
- [ ] 编辑检查针对变更范围，不对每次按键全量扫描；用可复现输入记录检查成本。
- [ ] 缩小后的恢复方式明确，至少保存重开可恢复普通功能；其他普通buffer仍能高亮及导航。
- [ ] 扩展已有editor/AI回归并更新大文件设计、教程和R03证据。

## 范围与交付记录

不调整阈值掩盖问题，不以全局关闭插件替代逐buffer保护。
