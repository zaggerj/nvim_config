# 13：让内置Tutor承接归档教程入口

**What to build（交付行为）：** 中文和英文教程入口可用，既有学习进度有明确保留方案，然后移除归档教程插件。

**Blocked by（阻塞依赖）：** 无（可开始）。

**Status：** ready-for-agent（用户已确认拆分与依赖，未开始实施；执行前须满足Blocked by）

**归属：** C；[治理SPEC](../spec.md) M01 / ID06；验收 AC08。

## 验收标准

- [ ] 盘点默认语言、进度格式和当前教程入口；先保存原进度，不覆盖源数据。
- [ ] 内置Tutor中文和英文入口实际可打开，现有帮助键可用。
- [ ] 验证进度保存差异，能迁移则验证；不能等价时明确说明并保留原记录，取舍未明确不删除行为。
- [ ] 无归档插件的隔离场景可正常使用教程并退出，不误接管其他命令。
- [ ] 更新依赖锁定、教程和决策回执。

## 范围与交付记录

不把完整操作教程重写成原生Tutor，也不删除原学习记录。

完成时追加复现、改动原因、执行环境/revision、实际结果、未验证边界和恢复方式；同步当前设计、教程、问题状态及决策记录。候选评估票以可复现比较和选型材料完成，不因评估结束自动获得迁移状态。
